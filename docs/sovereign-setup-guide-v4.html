Sovereignty Guarantee

All AI inference happens on-device. Ollama (UID 998) is blocked at the kernel level from making any outbound HTTP or HTTPS connections via iptables owner-match rules. Models cannot phone home, send telemetry, or exfiltrate data. The only intentional outbound traffic is SearXNG fetching web search results when a user explicitly enables web search, and n8n calling external APIs only when a user explicitly configures a workflow to do so.

Verify sovereignty at any time

# Confirm Ollama outbound is blocked
sudo iptables -L OUTPUT | grep ollama
# Expected: DROP rules for UID 998 on ports 80 and 443

# Confirm no AI service has active external connections
sudo ss -tnp | grep -E "ollama|n8n|chroma|searx" | grep -v 127.0.0.1
# Expected: empty output

SearXNG Installation

Privacy-respecting metasearch engine. Provides live web search for Open WebUI without routing queries through Google or Bing APIs.

Python 3.11 required. Ubuntu 22.04 ships Python 3.10 which lacks tomllib and has SQLite threading issues. Must use Python 3.11 venv explicitly.

Critical settings in /etc/searxng/settings.yml

# bind_address and port MUST be separate keys (combined format fails schema)
bind_address: "0.0.0.0"
port: 8888

# limiter must be false (no Valkey/Redis)
limiter: false

# valkey url must be empty string (commenting out fails schema validation)
valkey:
  url: ""

# JSON format required for Open WebUI
formats:
  - json
  - html

Wire into Open WebUI

Admin Panel → Settings → Web Search → enable Web Search → Engine: SearXNG → URL: http://192.168.1.100:8888

Enable per-chat by clicking the globe icon in the message input bar.
